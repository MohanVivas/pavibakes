# Pavi Bakes

Static bakery menu website for pavibakes.com.

## Publish with GitHub Pages

1. Create a public GitHub repository and push these files to `main`.
2. In the repository, open **Settings → Pages** and publish from the `main` branch, root folder.
3. Keep the `CNAME` file in the repository root and add the GitHub Pages DNS records at the domain registrar.
4. Enable HTTPS in Pages after the DNS check completes.

The `CNAME` file is set to `pavibakes.com`.
